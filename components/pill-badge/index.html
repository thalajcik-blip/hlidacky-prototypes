Pill Badge

Parent component to all the badges in the Hlídačky design system: 3 sizes, icons on either side, 21 colours, a hover state and a pulsing state. Every value on this page comes from the Figma component (Design System Hlídačky → Generic Badges → Pill Badge).

Playground

Pick any combination of the five Figma properties. The badge is live: hover it to see the hover state.

Sizes and icons

Heights 21 / 28 / 32 px. Small uses 12px text and 12px icons with 2×8 padding; Medium 14px text, 14px icons, 4×10; Large 14px text, 16px icons, 6×12. Gap is 4px everywhere. Shown in Light Green.

Colours and states

All 21 colours in every state, Medium with icons on both sides. The Rest and Pulsing columns also react to a real hover.

Pulsing (from the component description): a box-shadow ring grows from 0 to 8px while the accent colour fades from 55% to 0, every 1.6s on cubic-bezier(.2,.6,.4,1); the badge itself does not change size. With reduced motion it stays as the static ring Figma shows (4px, accent at 40%). The accent follows the Figma variants: on light colours it is the text colour, on solid colours the fill, and White uses Gray-600.
