When

What to try
  • Two clicks: an hour, then a minute. Clicking an hour already sets the time, so a full hour is a single click (close by clicking outside).
  • Type freely: 1830, 18, 18.30, 6:5 all work. Off-grid minutes like 18:05 are accepted.
  • Duration is kept: change From and To moves with it.
  • Overnight: pick an end before the start (e.g. 20:00 → 07:00) and it becomes the next day instead of an error.
  • Today: set the date to today and past times are disabled.
  • Keyboard: ↓ opens the picker, arrows move, Enter picks, Esc closes.
  • Mobile: the same <input type="time" step="900"> stays native. The picker only enhances it on desktop and submits the same HH:MM value.
