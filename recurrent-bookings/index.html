      What to try

      • + Repeat this booking opens a calendar of rolling weeks. Tap days to toggle them; what's selected is what gets sent. Show more weeks adds four.
      • Tap a column header (say Th) to select every Thursday from today on, again to clear them. Past days are left out.
      • The button says what happens: Done · N bookings, Use one date, or Keep the original when nothing is selected. Close or swipe down to discard.
      • With a series the date cell reads N dates and opens the calendar again, the price shows N × 450 Kč, and Remove repeat keeps the earliest date.
      • Several days (the calendar icon next to When) can't repeat: the link goes, and an existing series is dropped.

      What to try

      • Tap the date to open the sheet: the weekly strip first (swipe it sideways), or the month via Show monthly view. The sheet remembers the view you used last.
      • Tap From or To for the time picker: pick the hour, then the minutes, which closes it. Changing From keeps the length of the booking.
      • Overnight: set To earlier than From (say 22:00 → 08:00) and it becomes the next day, marked next day.
      • Several days: the calendar icon next to When switches to a from/to booking with its own dates. The end date can't be before the start. Tap the icon again to go back to a single day.
      • Repeat this booking opens its own sheet: pick the weekdays (the booking's own day comes ticked) and for how long. The dates it makes appear below; tap one to leave it out. Set N bookings turns the link into a summary with Edit and ×.
      • Send a repeated booking with more than one date and a confirmation screen lists each request. A single booking just shows a short note.
      • Only single days repeat: switching to several days drops the repeat, and the link isn't offered there.
